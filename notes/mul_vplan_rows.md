# Verification-plan rows - MUL part + ALU/DIV part (ready to paste)

Component names follow `tb_architecture/arch.jpg`: **Instructions agent**, **Data agent**,
**Reset agent**, **MUL agent (passive)**, **reg_file agent (passive)**, **ALU_MUL Scoreboard**,
**Predictor**, **Scoreboard**, **coverage_collector**, **Assertions** (bound to the DUT).
Names that do not exist in the architecture (`uvm_scoreboard`, `rvfi_monitor`,
`lsu_passive_agent`, `ref_model`, `sys_ctrl_*`) are replaced below.
Implemented names: scoreboard message ids `SB_MUL_RESULT`, `SB_MULH_RESULT`, `SB_MUL_WB`,
`SB_MUL_LATENCY`, `SB_MUL_TAG`, `SB_ALU_RESULT`, `SB_DIV_RESULT`, `SB_ALU_LATENCY`, `SB_DIV_LATENCY`,
`SB_ALU_WB`, `SB_ALU_TAG` (tb/env/alu_mul_scoreboard.sv); covergroups `cg_op_operands`,
`cg_result`, `cg_timing`, `cg_regs`, `cg_sequence`, `cg_reset` (tb/fcov/mul_cov.sv) and `cg_op`,
`cg_alu_operands`, `cg_shift`, `cg_branch`, `cg_div`, `cg_div_timing`, `cg_seq`, `cg_reset`
(tb/fcov/alu_cov.sv); assertions `A_*` / covers `C_*` (tb/assertions/mul_sva.sv, alu_sva.sv);
sequence `mul_program_seq` (tb/sequences); tests in tb/tests/README_mul_tests.md.
